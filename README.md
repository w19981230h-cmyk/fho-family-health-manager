# FHO 家庭健康管理师

家庭健康管理师工作平台静态原型，包含工作台、客户管理目录、获客管理，以及随项目发布的界面打点备注。

## 批注说明

右上角批注工具默认隐藏点位。点击“显示批注”可查看当前界面备注，点击“批注汇总”可跨界面阅读全部产品规则。线上版本采用只读快照，备注数据来自 `annotations.json`，避免把浏览器本地数据误认为多人共享数据。

## 运行

直接打开 `index.html`，或在当前目录启动任意静态文件服务器。

```powershell
python -m http.server 8000
```

浏览器访问 `http://localhost:8000`。
